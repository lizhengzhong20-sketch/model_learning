# 第 0 章：学前必读 🗺️

> 这一章不讲任何模型，只讲一件事：**怎么把这套知识库用好**。读完你会知道每一页该怎么读、从哪里进入这棵知识树、卡住了去哪找答案——然后再决定要不要装环境（第 1 章）、补多少数学（第 2 章）。

## 🧭 这套知识库是什么 · 不是什么

| 它是 ✅ | 它不是 ❌ |
|--------|-----------|
| **教材 + 百科**：像教材一样成体系，像字典一样随时按需查阅 | 打卡课程：没有进度表、不需要连续签到、更没有"多少天学完"的承诺 |
| **一棵知识树**：每个概念都标明上下游依赖，章与章之间全部可跳转 | 论文合辑：不假设你先读过原始论文，公式出现必配一句"人话" |
| **练手场**：每页都有能跑的最小代码、常见误区与折叠自测 | 题库或热点搬运：不为背知识点而写，不追逐一周热点 |

一句话：**它是地图，不是任务清单**。地图允许你走岔路、抄近道、原地折返——只要最终知道自己在哪、要去哪。

## 📖 一页正文怎么读

本库每个主题页都长一个样，小节顺序就是推荐的阅读顺序：

```mermaid
graph LR
    A["📌 解决什么问题"] --> B["🌱 通俗理解"]
    B --> C["📋 举个例子"]
    C --> D["🧠 核心原理"]
    D --> E["💻 动手试试"]
    E --> F["🔥 炼丹小灶"]
    F --> G["🖱️ 动手玩"]
    G --> H["🔗 知识树位置"]
    H --> I["⚠️ 常见误区"]
    I --> J["📝 小结与自测"]
    J --> K["📚 延伸阅读"]
```

| 小节 | 干什么 | 第一遍要读吗 |
|------|--------|--------------|
| 📌 解决什么问题 | 交代这个技术出现前的困境与它的思路 | 必读，花半分钟判断这页和你有没有关系 |
| 🌱 通俗理解 | 生活化类比 + 白话，零公式 | 必读，直觉先于公式 |
| 📋 举个例子 | 带具体数字或小场景走一遍 | 必读，抽象概念落地全靠它 |
| 🧠 核心原理 | mermaid 图解 + 公式，每个公式跟一句"人话" | 第二遍再啃也来得及，长推导都折叠了 |
| 💻 动手试试 | 最小可运行代码 + 预期输出 | 强烈建议跑一遍 |
| 🔥 炼丹小灶 | 工业界常用起点配方与玄学 | 顺手看看，当经验参考 |
| 🖱️ 动手玩 | playground 或经典交互工具链接 | 值得点进去拖两下滑块 |
| 🔗 知识树位置 | 上游是什么、下游通向哪、与谁并列 | 用来规划路线与复习 |
| ⚠️ 常见误区 | 典型错误理解与澄清 | 复习和面试前重点看 |
| 📝 小结与自测 | 要点回顾 + 折叠答案自测 | 必做，讲不出来就是没懂 |
| 📚 延伸阅读 | 论文、课程、博客 | 需要深挖时再用 |

**核心建议：第一遍只读 📌 → 🌱 → 📋，先搞清"这页在讲什么"；公式与推导放第二遍，代码随手跑。** 页面顶部标着难度星级、所属分支与前置知识，底部有上一页/下一页翻页导航——像读教材一样顺。

## 🚦 三种读法，总有一款适合你

不同目的的人，进入这棵树的路径不同。这里只给一行概览，完整路线（含方向选择建议）见 [🗺️ 知识地图与阅读路线](../../../ROADMAP.md)：

- **读法 A · 建立全局认知**：跳读主干——学前必读 → 数学基础各页的"通俗理解" → 机器学习全景 → 深度学习基础 → LLM 全景 → 前沿地图。适合要听懂算法团队在说什么的产品、管理与运营同学。
- **读法 B · 系统通读**：第一篇到第五篇顺读，第四篇七大方向按目标选一两个深入。适合想完整建立 AI 知识体系的读者，每页"动手试试"都值得跑。
- **读法 C · 直奔大模型**：已有 Python 与基础机器学习功底时，从第 7 章 NLP 与 LLM 直接进入，再回补强化学习与生成模型。适合想转入大模型方向的读者。

## 🎯 阅读方法四条

1. **费曼技巧**：每读完一页，合上文件，用自己的话把"通俗理解"讲一遍——讲不顺的地方，就是没懂的地方。
2. **代码必跑**：每页"动手试试"不能只看。跑一遍、对照预期输出，是最便宜的正确性检验。
3. **改参数做实验**：把示例的学习率、层数、数据量改一改再跑，观察结果变化——手感来自"改了之后会怎样"，而不是"看过"。
4. **输出倒逼输入**：读完一章写一篇小结，或给本库提一条修订——写不出来的地方，就是理解的地基没打牢。

## ❓ 常见问题 FAQ

<details>
<summary>数学不好，能读吗？</summary>

**能。** 本书默认读者只会一点 Python，公式出现时必配一句"人话"解释。第 2 章数学基础的第一遍只需建立"知道去哪查"的印象，后续篇章**用到再回看**。真正卡住人的往往不是数学，而是没把类比和例子读懂——先读 🌱 和 📋，再回头看公式。

</details>

<details>
<summary>必须按顺序从第 0 章读到第 12 章吗？</summary>

**不必。** 知识树是地图，不是任务清单。主线（起步准备 → 经典机器学习 → 深度学习 → 专业方向 → 前沿与融合）适合系统学习者；赶时间的读者按 [ROADMAP](../../../ROADMAP.md) 的三种读法选路即可。唯一提醒：跳读时瞄一眼每页顶部的"前置知识"，缺了再回补，别硬啃。

</details>

<details>
<summary>内容会更新吗？技术迭代这么快怎么办？</summary>

**会。** 本库按"小步提交、持续推送"的节奏演进，每次变更都记录在根目录的 `CHANGELOG.md` 里。新技术按贡献指南的三级扩展机制落位：先进第 12 章"前沿技术地图"登记，成熟后独立成页、成章——**只往后加，不推倒重来**，你收藏过的页面链接不会失效。

</details>
