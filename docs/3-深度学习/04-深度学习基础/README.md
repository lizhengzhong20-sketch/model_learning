# 第 4 章：深度学习基础 🧠

> 第 3 章的世界里，喂给模型的特征要靠人手工设计；本章跨过这条分水岭——**特征交给神经网络自己学**，这就是表示学习（Representation Learning）。本章五页正文加一页生产实战，从"网络怎么算"一路讲到"多卡怎么训、上线怎么跑"，是第四篇所有专业方向共同的地基。

## 🧭 本章定位：从"手工设计特征"到"自动学特征"

在第 3 章的经典机器学习里，模型再强，也只能吃到人喂给它的特征：预测房价要先造"每平米单价"，识别垃圾邮件要先数"可疑词个数"。特征设计得好不好，直接决定模型上限——这一步被称为特征工程（Feature Engineering），也是过去算法工程师最花时间的地方。

深度学习（Deep Learning）换了一条路：把原始数据（像素、字符、声音采样）直接丢进一个多层神经网络，让**每一层自动把表示加工得更抽象**——从像素到边缘、从边缘到部件、从部件到物体。人不再告诉模型"该看什么"，模型自己学出"该看什么"。

那经典机器学习是不是被淘汰了？并没有，两边的地盘大致是这样的（经验法则）：

| 数据形态 | 通常更强的方案 | 原因 |
|----------|----------------|------|
| 图像、文本、语音等原始高维数据 | 深度学习 | 手工特征设计不动，自动学特征碾压人工 |
| 结构化表格数据（如用户行为表、金融特征表） | 梯度提升树（如 XGBoost / LightGBM） | 表格特征本来就"人类可读"，树模型快、稳、好调 |

所以本章不是"取代第 3 章"，而是补上另一件武器——遇到图像、文本这类原始数据时，你需要它。

## 🧭 怎么读这一章（按目标选深度）

- **快速过一遍（建立地图）**：按顺序读每页的"一句话理解 → 通俗理解 → 举个例子 → 小结"，跳过所有折叠框——约一小时的骨架之旅；
- **认真学一遍（默认推荐）**：全部小节都读，折叠框里的推导与算例逐个展开跟着算——本章手算数字前后贯通（第 1 页的 0.655 在第 2 页继续追责），算一遍胜过看三遍；
- **带着问题来查（工具书用法）**：训练不收敛 → 直奔第 2 页排查决策树；报错看不懂 → 第 3 页报错对照表；显存/算力不够 → 第 4 页两本账；上线慢/贵 → 第 5 页成本账本与加速链路。

## 🎯 读完本章你应该能

- 手算一个迷你神经网络的前向传播，说清激活函数为什么必须非线性，并能按"梯度特性 + 症状"为网络选激活函数；
- 写出两层网络全部参数的梯度（含 ∂L/∂W₁ 的完整链式展开），会打印梯度范数诊断消失/爆炸，按五步决策树排查"损失不降"；
- 用 PyTorch 的 Tensor、autograd、nn.Module、DataLoader 四件套把训练循环工程化，分清 detach/no_grad/inference_mode，选对保存方式，修掉最常见的六类报错；
- 建立"参数量→显存→算力"的量级直觉（16~20 字节/参数、6ND），说清数据/张量/流水线并行与 ZeRO 各自在拆什么、代价是什么；
- 把训练好的模型导出 ONNX 并实测加速比，解释量化、蒸馏、算子融合各自提速的原理，并用 P99、QPS、每百万 token 成本评估一个线上服务。
